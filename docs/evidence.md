# Evidencia de evaluación

Guardar capturas de:

1. Historial de commits y ramas.
2. Pull Requests y revisiones.
3. Ejecuciones exitosas de CI.
4. Tags SemVer.
5. Imagen publicada en GHCR.
6. Deploys de Render.
7. Logs y health checks.
8. `render.yaml` como IaC.
9. Pruebas automatizadas.

Cada evidencia debe permitir identificar rama, commit, fecha y resultado.
